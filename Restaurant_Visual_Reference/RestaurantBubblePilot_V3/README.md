## 验收要点（供参考，不作结论）

1. 两处暗盘缘弧线是否已从 V3 中消失，有无残影或色带。
2. 双椭圆描边、尾部、阴影与外部背景是否完整。
3. 气泡内部暖白渐变是否自然，有无色块、矩形边界、模糊污渍。
4. R2 左下终止处是否出现新的可见弧线或接缝。
5. 低饱和盘缘与阴影是否保留质感（不要只看高饱和菜品像素）。

本轮仅作图片交接与自检，**不对 V3 作最终质量验收**，等待独立审阅结论。

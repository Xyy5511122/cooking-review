RiderY(index2) 虚拟鼠标输入验证（独立 Unity Input System 设备）

=== 设备与注入方式 ===
- 设备：AddDevice<Mouse>("RiderYDragVirtualMouse" / "IsoVirtualMouse" / "IncVirtualMouse")
- device id：27 / 28 / 29（各次独立 Play 会话）
- interfaceName：[]（空 = 非 RawInput，非实体设备）
- 注入：InputSystem.QueueStateEvent(vm, new MouseState{ position, buttons })，
  buttons=(ushort)1 表示左键按下、0 表示松开
- 时序：ADD→MOVE(松开)→PRESS→跨≥4 帧→12 步移动→跨≥3 帧→RELEASE→跨≥4 帧
  （PointerSystem 依赖 wasPressedThisFrame / wasReleasedThisFrame 边沿，必须跨真实帧）
- 未使用或控制用户实体鼠标；未用自动化工具抢占桌面输入。

=== 真实处理链路上菜 ===
- PRESS 后：PointerSystem.Instance.IsDragging = True，CurrentDrag = dish_potato_cake
  （证明命中检测/BeginDrag 生效）
- 拖动中：item 位置从 bowl(780,161) 移动到 (880,457) 再到骑手 (880,415)
- RELEASE 后：经过 DropZone.OnDrop → TryServeBowlDish → ServeOne → TakeoutServed

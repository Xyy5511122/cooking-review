发现的问题：1280x1024（5:4）下 Girl 气泡与耐心条被右侧裁切
==========================================================

证据文件
--------
- resolution_1280x1024.png（完整 Play 截图）
- resolution_1280x1024_bubble_zoom.png（对应区域放大）
- resolution_1920x1080.png / resolution_1844x1037.png（对照：16:9 下完整显示）

运行时读数（Screen = 1280x1024）
-------------------------------
CanvasScaler：
  uiScaleMode = ScaleWithScreenSize
  referenceResolution = 1920 x 1080
  matchWidthOrHeight = 0.5
  Canvas.scaleFactor = 0.7950464
  Canvas.pixelRect = (0,0,1280,1024)

RectTransform 世界角点：
  Boy (T0) bubble: x = 91 .. 363, y = 533 .. 695   -> 完全在屏幕内
  Girl (T4) bubble: x = 1159 .. 1382, y = 522 .. 646 -> 右缘超出屏幕宽度约 102 px

现象
----
5:4 宽高比下，画面右侧的 Girl 气泡最右边约 102px 被裁掉；其下方耐心条也在右缘被裁切。
1920x1080 与 1844x1037 下两桌气泡、图标、耐心条、人物均完整，未发现裁切或重叠。

归因（只读分析，未修复）
------------------------
该裁切来自工程现有 CanvasScaler 缩放策略：以 1920x1080 为参考分辨率且 matchWidthOrHeight=0.5，
在明显更窄的 5:4 视口下，画布逻辑宽度仍按参考宽度布局，导致最右侧的 Girl 区域超出屏幕。
这不是 Girl V2 图标或气泡素材引入的问题；原静态气泡处于同一位置，同样会超出屏幕。
按本轮“只测试、不修复”的约束，未调整 Canvas Scaler、锚点或任何布局参数。

影响范围
--------
- 16:9（1920x1080、1844x1037、796x448）：未发现异常。
- 5:4（1280x1024）：右侧 Girl UI 被裁切，属于需要单独评估的工程布局问题。
- 本轮未在 1280x1024 下执行鼠标拖拽，因此未验证该分辨率下的交互热区是否仍可点击。

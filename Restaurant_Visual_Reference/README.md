# 餐厅端视觉参考图（给外部评审用）

本目录收录餐厅端的三张关键截图，供对照「目标效果」与「当前实现」。均为游戏素材/画面，不含任何个人信息。

| 文件 | 说明 |
|---|---|
| `01_target_sample_full.png` | 用户提供的满员样板图（理想效果）：5 位顾客、黄圆脸+绿黄红耐心条、白色气泡菜盘全部画死在图里 |
| `02_current_full.png` | 当前实现的满员画面：成品图当底 + `mask_*` 遮罩控制陆续到店 + 白条从右往左推进表示耐心下降 |
| `03_current_prepare.png` | 当前实现的准备阶段：`PrepCleanCover` 空店整图盖层，画面完全干净、无人 |

配套的《餐厅端问题总结》（含六轮返工踩坑史、坐标数组、遗留问题）见仓库 `Restaurant_Visual_Reference/REVIEW_SUMMARY.md`。

## 给评审者的对照要点

1. 样板图（01）是必须 100% 复现的目标；当前实现（02）在其上叠加了动态信息。
2. 准备阶段（03）必须是完全干净的空店，与样板满员图形成"陆续来人"的前后关系。
3. 已知遗留：圆脸表情不随耐心变化；气泡菜是画死的、与真实订单可能不符且上菜不变灰；顾客离场无淡出。

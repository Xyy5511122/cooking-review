Uncle 气泡图标实际可见边界计算（验证 B）
==========================================
说明：本文件区分「RectTransform 边界」「Sprite 透明alpha边界」「最终可见像素范围」三种口径。
所有数值来自 1920×1080 Play Mode 运行时读数 + 源 PNG 独立像素扫描，非肉眼估计。

一、输入数据（全部实测）
------------------------------------------------------------
[运行时 RectTransform，左下原点，屏幕像素]
  bubble Rect : x 628.000 .. 868.000   y 682.000 .. 814.000
  icon   Rect : x 681.936 .. 814.065   y 695.936 .. 828.065
  icon sizeDelta = (132.129, 132.129) ; pivot = (0.5, 0.5)
  Canvas.scaleFactor = 1.000000
  Image.type = Simple ; preserveAspect = false

[Sprite]
  sprite name = food_dish_pepper_beef
  texture = 1024×1024
  textureRect = (x 75.1, y 80.0, w 873.8, h 864.9)  // Unity 左下原点
  → 纹理内有效区（左下原点）：x 75.1..948.9 , y 80.0..944.9

[源 PNG alpha>32 包围盒]（独立读取 Unified_v2/food/food_dish_pepper_beef.png）
  图像坐标（y 自顶向下）：x 78..945 , y 82..941
  alphaW = 868 , alphaH = 860 , cx = 511.5 , cy = 511.5
  与 DiningTable.cs 中 BubbleIconFit{texture=1024, alphaW=868, alphaH=860, cx=512, cy=512} 一致
  （cx/cy 0.5px 取整差，不影响边界）

二、计算链路
------------------------------------------------------------
Image.Type.Simple + preserveAspect=false 时，Sprite 的 textureRect 被铺满整个 icon Rect。
alpha 可见区在 textureRect 内的归一化位置：
  u0 = (78 - 75.1)/873.8   = 0.00332
  u1 = (945+1 - 75.1)/873.8 = 0.99668
  v0（自下）= (944.9 - 941)/864.9 = 0.00451
  v1（自下）= (944.9 - 82)/864.9  = 0.99849

映射到 icon Rect（左下原点）：
  visible x0 = 681.936 + 0.00332×132.129 = 682.38
  visible x1 = 681.936 + 0.99668×132.129 = 813.62
  visible y0 = 695.936 + 0.00451×132.129 = 696.53
  visible y1 = 695.936 + 0.99849×132.129 = 827.82

换屏幕坐标（y 自上向下 = 1080 − bottom-origin y）：
  visible x : 682.4 .. 813.6
  visible y : 252.2 .. 383.5

三、对比结论
------------------------------------------------------------
[气泡 Rect 范围]
  x 628..868 , screen y 266..398 （bottom-origin y 682..814）

[两种口径的越界量]
  1) 按 RectTransform：
     icon Rect 顶 y=828.065 > bubble Rect 顶 y=814 → 越出 14.07 px
  2) 按 Sprite 非透明像素（真实可见）：
     visible 顶 y≈827.82（screen y≈252.2）> bubble Rect 顶 y=814 → 越出 13.82 px
     visible 底 y≈696.5 < bubble Rect 底 y=682 → 在气泡内（余 14.5 px）
     visible 左右 682.4..813.6 均落在气泡 x 628..868 内（余 54.4 / 54.4 px）

[是否仅 RectTransform 超出而 Sprite 透明边未越界]
  否。Sprite 的非透明像素本身就越出了气泡 Rect 上缘约 14 px。
  这 14 px 不是透明边缘——源 PNG 在这段范围内有真实 alpha 像素。

[是否压到气泡描边 / 尾巴]
  气泡椭圆描边顶在裁片内约 y=7（132 高裁片，底图 y=273 → screen y≈273）。
  图标可见顶部 screen y≈252，比描边顶 y≈273 高约 21 px → 圆盘压在描边之上、
  并露到气泡外的玻璃门背景。放大图 uncle_bubble_zoom.png 中央列像素扫描印证：
    screen y=263 处为气泡描边暗棕 (99,56,33)
    screen y=265 处已是盘子白边 (247,248,247)
    screen y=281 起为青椒绿色 (70,154,61)
  即图标可见像素从 y≈252/265 开始，位于描边/气泡上缘之外。
  尾巴位于气泡下方偏左（底图约 x705,y392），图标底部 y≈696(bottom-origin) 远高于尾巴，
  未压到尾巴。

四、最终判定
------------------------------------------------------------
可见菜品【未】完全落在气泡内部：顶部约 14 px（相对 bubble Rect）/ 约 21 px（相对描边）
的真实非透明像素越出气泡上缘，视觉上圆盘骑在气泡拱形描边上并露出背景。
这不是「RectTransform 超出但透明边未越界」的假象。
数据仅供审阅判定；本轮未修改任何图标布局参数。

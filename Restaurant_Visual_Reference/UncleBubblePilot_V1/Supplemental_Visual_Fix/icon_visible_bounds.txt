Uncle 单菜图标可见边界（实际渲染像素差分）
==========================================

条件
----
分辨率：1920×1080 Play Mode
Canvas.scaleFactor：1.000000
场景：Boy(index0) 双菜 / Uncle(index1) 单菜 / Girl(index4) 三菜，同时到店
方法：同一帧状态下，分别截取 dishIconRoots[0] 显示与隐藏的全屏图；
     逐像素计算 max(|ΔR|,|ΔG|,|ΔB|)>12 的连通范围，作为图标真实可见像素 bbox。
     暖白内缘与暗色描边/尾巴由隐藏图标的截图分类得到。

气泡 Rect（运行时实测）
----------------------
x = 628 .. 868 （bottom-origin 同值）
bottom-origin y = 682 .. 814
屏幕 y（自上向下）= 266 .. 398

修正前
------
icon Rect (bottom-origin) : x 681.936 .. 814.065 , y 695.936 .. 828.065
icon sizeDelta            : 132.129 × 132.129
icon anchoredPosition     : (120, 80)
实测可见像素 bbox         : x 692 .. 803 , 屏幕 y 262 .. 345
可见尺寸                  : 112 × 84
可见中心                  : (747.5, 303.5)
同 x 范围暖白内缘         : y 282 .. 345
顶部余量                  : 262 - 282 = -20 px（压住描边/暖白外）
底部余量                  : 345 - 345 = 0 px
相对 bubble Rect 顶       : 262 - 266 = -4 px（越出矩形上缘）
到暖白/描边内缘最小距离   : 0.00 px
到尾巴暗像素最小距离      : 25.00 px

修正后
------
icon Rect (bottom-origin) : x 705.530 .. 790.470 , y 721.530 .. 806.470
icon sizeDelta            : 84.940 × 84.940
icon anchoredPosition     : (120, 82)
实测可见像素 bbox         : x 712 .. 783 , 屏幕 y 280 .. 345
可见尺寸                  : 72 × 66
可见中心                  : (747.5, 312.5)
同 x 范围暖白内缘         : y 278 .. 345
顶部余量                  : 280 - 278 = +2 px
底部余量                  : 345 - 345 = 0 px（止于最后一个暖白像素行，未越出）
相对 bubble Rect 顶       : 280 - 266 = +14 px（在矩形内）
到暖白/描边内缘最小距离   : 1.00 px
到尾巴暗像素最小距离      : 25.00 px
暖白安全区中心            : y (278+345)/2 = 311.5；图标中心偏差约 1 px

口径说明
--------
补充验证 235023f 用 Sprite.textureRect + PNG alpha 包围盒推算，得到“越出 Rect 约 14px、越出描边约 21px”。
本轮以实际渲染差分测得“越出 Rect 顶 4px、压入暖白内缘 20px”。口径不同，但结论一致：
修正前圆盘真实像素覆盖描边并露到背景；修正后已完整落入暖白内部。

## 一、结论摘要

V2 没有推翻 V1，而是在 V1 基础上按审阅意见做定点返修：

1. **右下弧线**：重新判定为**原右盘盘缘/盘影**，不是气泡描边。其深棕弧线与最大暗色连通域（真实气泡描边）**不相连**。V2 已清除该盘缘主体。
2. **两盘间 V 形痕迹**：是两盘盘缘与 V1 清理边界叠加形成的残留，V2 增加中间桥接清理区后已消除。
3. **左侧锯齿/椭圆修补边界**：V1 的底色估计在左侧列采样失败后被暖色外推，导致桃色椭圆边。V2 改用严格干净暖白像素的高斯加权重建，并加入 8px 羽化，左侧明显平滑。
4. **暖白渐变**：保留原图暖白、边缘自然阴影，不再使用 V1 的硬椭圆色块填充。

最终候选在 1×、3×、5× 和覆盖回原背景后检查中，未再看到可辨认的深棕盘缘弧线或 V 形痕迹；右/左侧仍各有一条极淡过渡带，位于真实描边保护区内或属于气泡自然阴影，详见第六节。

## 二、右下弧线的重新判定（本轮最重要证据）

上一轮把右下弧线认定为“气泡描边向上收的走向”。本轮不沿用该曲线模型，改为对**原图暗色像素做连通域分析**：

- 真实气泡描边 + 尾巴：最大连通域，**2369 px**，bbox x[12..279] y[0..150]。它沿气泡最外圈连续闭合，并经尾巴延伸。
- 左盘盘缘：独立连通域，**161 px**，bbox x[48..141] y[60..102]，与描边不相连。
- 右下深棕盘缘弧线：独立连通域，**63 px**，bbox x[181..232] y[99..105]，与描边不相连。
- 右侧盘缘侧边：独立连通域，**38 px**，bbox x[239..252] y[75..95]，与描边不相连。
- 两盘之间的小段盘缘也均为独立小连通域，未并入最大描边域。

证据图：`stroke_component_analysis.png`（4×，红色为最大描边连通域，其余颜色为独立盘缘/背景连通域）。

因此结论明确：**候选图中那条与最外侧描边明显分离的弧线是盘缘残留，不是气泡描边**。V2 中上述 63px、38px 盘缘连通域的实际修改结果均为 0 个未改像素；最大描边连通域 2369px 全部原样保留。

## 三、V2 相对 V1 的具体改动

| 项目 | V1 | V2 |

| 填充来源 | 上/下逐列采样插值；左侧列无有效样本时暖色外推 | 严格筛选原气泡内干净暖白像素，σ=22 高斯加权估计 |
| 描边附近过渡 | V1 曲线保护带 | 保护区外 3px 内逐渐淡出，避免硬接缝 |

- 左盘主体 + 下方盘影：`ell(86,69,60,35) ∪ ell(88,97,58,15)`
- 右盘主体 + 右下盘影：`ell(202,69,61,35) ∪ ell(211,98,57,17)`
- 两盘间桥接：`ell(150,92,24,23)`

清理区外再做 8px 羽化；真实描边保护区内置 alpha=0，任何描边像素不被改动。

## 六、仍然保留原始像素的区域及原因

1. **气泡最外描边与尾巴**：最大暗色连通域 2369px 全部保留；这是气泡轮廓本体，不属于盘缘。
2. **描边外侧与气泡外部纹理**：所有清理区外像素逐像素保持原图。
3. **右下极淡灰白过渡带**：约 x[202..270] y[85..115]，按亮度 <235 粗略统计 1011px，其中多数是真实描边、抗锯齿和气泡自然内侧阴影；靠近描边的浅色盘影仅剩极淡过渡，无法在不触碰描边的前提下继续安全清除。
4. **左侧贴描边极淡弧带**：约 x[25..48] y[40..110]，按亮度 <235 粗略统计 268px；主要包括气泡左侧自然阴影及距真实描边 <8px 的窄段，按安全约束保留。
5. **两盘之间**：未发现按亮度统计的残留暗像素；中央 V 已清除。

以上保留区域均已在 12×/10×/8× 放大中复核；没有为了像素指标而牺牲描边安全，也没有把可安全清除的盘缘主体误划入保护区。

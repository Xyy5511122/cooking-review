## 二、素材制作说明

### 1. 底图
直接使用 Unity 当前引用的原始背景图 `restaurant_full.jpg` 的像素裁片，**未经压缩、缩放、截图或二次编辑**。裁片 280×156，覆盖源图 `(1458,268)`–`(1737,423)`。裁片四周保留描边外侧少量背景与纹理。

### 2. 清理范围与方法
- **清理对象**：气泡内两道静态菜品及其盘子——左盘番茄炒蛋（裁片 x≈30..142, y≈38..110）、右盘饼（裁片 x≈145..262, y≈38..110）。
- **定位方法**：先用暖白连通域 + 深棕描边屏障 flood-fill 精确得到气泡内部 mask（22003px），再用番茄红/饼黄颜色特征逐行扫描确定菜品真实 y 范围（y≈44..92），据此建立两个清理椭圆：`(cx,cy,rx,ry) = (86,69,58,41)` 与 `(201,69,57,41)`，外加 1px 膨胀覆盖抗锯齿盘缘。
- **填充方法**：局部背景重建。在气泡内上方（y=20..34）与下方（y=112..118）分别逐列采样干净暖白像素，做列方向插值（smoothstep，yt=30→yb=112）生成逐列渐变底色；只在清理 mask 内用该底色替换原像素。未使用矩形填白、纯色覆盖或整块模糊。
- **渐变与质感**：采样自原图同背景的暖白像素，保留原有暖白渐变方向与轻微色调；气泡外部、描边、尾巴像素一律不改。

### 3. 描边保护区定义（沿 Boy V3 保护标准）
- 以裁片坐标手工精读气泡描边内缘，建立**左 / 右 / 上 / 下 / 尾巴**五段描边曲线：
  - 左缘 x≈9..40（随 y 变化），右缘 x≈238..271，上缘 y≈14..44，下缘 y≈90..122，尾巴 x[163..198] y[116..156]。
- 各曲线向外扩 8px 建成保护带（其中尾巴区域整体设为保护带），再 1px 膨胀抗锯齿；保护带共 10773px。
- **硬约束**：计算每一个实际被修改像素到保护带的最短欧氏距离，必须 ≥8px；不满足者一律保留。共 1468 个候选像素因 <8px 被拒绝修改。实测全部 15127 个修改像素的**最小距离为 8.00px**，达标。

## 三、未清理干净的区域（如实说明）

- 候选图右下方向仍可见**一条极淡的弧形痕迹**（裁片约 x[180..244], y[95..114]），以及两盘之间**极淡的小点痕迹**。
- 经精确像素复核：这些像素到描边保护带的距离为 **0.00–7.62px，全部 <8px**，严格落在描边保护区内，**按约束不可清理**。
- 进一步核对原图描边走向发现：右下弧线所在位置正是气泡描边向上收的真实走向（例如原图 x=204 处深棕描边已在 y≈95..105），因此该弧线**部分属于气泡描边本体**，必须保留；强行清除会破坏气泡轮廓。
- 缩小到接近实际游戏显示尺寸（0.75×）复核：这些痕迹极淡、不明显，气泡整体呈现为干净的空白对话气泡。
- 结论：**存在极淡残留，但均在 8px 保护约束内或属描边本体，按规则保留，未强行修补。**

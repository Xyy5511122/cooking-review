最终只镜像了一张 PNG。现在用户宣布完工并要求按既定通道送外部评审。

## 7. 评审方在 N2 只回答一个问题

**数字与结论之间有没有矛盾？** 例如：某条 FAIL 但结论写「已达标」；某条 PASS 但结论写「待改进」；
或结论写了 `FACTS.md` 里根本没有数字支撑的内容。

输出沿用 `PROTOCOL.md §5` 的 `VERDICT + 最多 8 条 + 最严重一条后果` 格式，
每条必须引用 `SPEC.md` 的条款编号（`N2-01`…`N2-16`、`B1`…`B4`、`C`、`D`、`E`）。
问题类型请用：`数字矛盾` / `无证据` / `流程缺陷` / `口径混用`。
发现标准缺失时记「规格缺陷」，不要在验收现场补标准。

## 本节点将包含什么

| 内容 | 来源 |
|---|---|

## 评审方在 N2 只回答一个问题

**数字与结论之间有没有矛盾？** 例如：某条 FAIL 但结论写"已达标"，或某条 PASS 但结论写"待改进"。

不评判美观，不评判实现方式。美观由用户看截图判定。

## 一条纪律

N2 不允许新增标准。若验收时发现 `SPEC.md` 缺了某条，结论记为「规格缺陷」，回到 N1 修订并升版本号，不在验收现场改标准。

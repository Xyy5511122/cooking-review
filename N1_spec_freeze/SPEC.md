# SPEC — 土豆切面 A-2 / 丝束 v06（N1 冻结版）

所有阈值由 `tools/asset_lint.py --spec cutface|strip` 判定，不靠肉眼。数值来源见 §C。

---

## §0 共同约束（两批资产）

| 项 | 值 | 来源 |
|---|---|---|
| 引擎 | Unity 6（6000.4.7f1） | 项目 |
| 导入 | Sprite (Single)、FullRect、PPU 100、无 mipmap、无压缩、Alpha Is Transparency | 现有 `.meta` |
| 背景 | 全透明，轮廓只由 Alpha 表达，不允许白底/黑底/描边兜底 | 用户原话 |

## §A 切面 A-2

| 条款 | 要求 | 判定方式 |
|---|---|---|
| **A1** | 画布 1024×1024 | 文件像素尺寸 |
| **A2** | Alpha bbox = (464, 46, 96, 819)，误差 ≤2px | alpha 包围盒 |
| **A3** | 非矩形：`straight ≤0.55` | 轮廓停留在最大宽度（±5%）的最长连续段 / 长轴长度 |
| **A4** | 两端圆润：`endTaper ≤0.55` | 两端各 4% 长度内平均厚度 / 最大厚度 |
| **A5** | 无深描边：`edgeLum ≥150` | α>200 区域内、距边缘 6px 带内最暗亮度（0–255） |
| **A6** | 内部为浅黄奶白，单色占比不做硬性判定 | 仅记录 top-3 量化色，供用户判断 |

补充（不进入机器判定，写进提示词）：

- 轮廓必须整体连续外凸，不允许出现直边超过总高的一半；
- 不出现薯片、薯条、煎炸色、卡通土豆、盘子、刀、手、投影；
- 切面与土豆主体的衔接由既有 uv 映射保证，贴图内不加阴影。

## §B 丝束 v06（6 张独立文件）

| 条款 | 要求 | 判定方式 |
|---|---|---|
| **B1** | 画布 512×512，共 6 张，逐张独立（禁止六格组图） | 文件尺寸与数量 |
| **B2** | Alpha bbox 宽 240–300、高 105–145 | alpha 包围盒 |
| **B3** | 整体轮廓：`solidity ≥0.88` | 轮廓面积 / 凸包面积 |
| **B4** | 边缘不碎：`compact ≥0.30` | 形状因子 4πA/P² |
| **B5** | 有束腰：`waist ≤0.70` | 中段 30–70% 最薄厚度 / 全局最厚 |
| **B6** | 两端收尖：`endTaper ≤0.30`（**保持项**，现有素材已满足 0.12–0.26） | 两端 4% 平均厚度 / 最大厚度 |
| **B7** | 无深描边：`edgeLum ≥120` | 同 A5 |
| **B8** | 六张之间形态互异但同一食材、同一风格 | **无量化方法，由用户判**（见 D6） |

补充（写进提示词，不进入机器判定）：

- 一束内 10–14 根细丝（目标 12 根）；
- 单根细丝必须可辨认，但不得互相散开成无组织的线；
- 颜色为土豆浅黄 / 淡奶油黄，不取炸薯条的金黄；
- 六张各自独立输出，不得改变画布范围或引入组图间距。

## §D 已知风险与不可判定项（自我披露）

| # | 风险 | 影响 |
|---|---|---|
| D1 | 参照图只证明"数值可达"，不证明"好看"。结论：**达标 ≠ 可采纳**，最终仍需用户看图 | 可能全项 PASS 但用户否决 |
| D2 | B5 阈值 0.70 与现有素材下限 0.71 只差 0.01，存在"为过阈值而过度束腰"的风险 | 可能产出腰过细、不像自然束 |
| D3 | A4 阈值 0.55 位于矩形 0.94 与椭圆 0.27 之间，**中间地带无样本**，属插值猜测 | 可能放过"轻微圆角矩形" |
| D4 | A2 的 ±2px 定位对生成式模型几乎不可达，实际会迫使程序化生成或后期归一化 | 工具选型被技术条款倒逼 |
| D5 | B4 的 compact 对内部丝缝敏感：缝越多周长越长、指标越低，可能惩罚"丝感清晰"的正确做法 | 可能误判好素材 |
| D6 | **B8 不可判定**。六张"形态互异"没有量化方法，只能人工看 | 规格中存在一个主观条款，已知 |
| D7 | 全部指标都是 2D 轮廓统计，不衡量"材质感/颜色层次"，后者完全由用户判断 | 数字通过不代表质感合格 |
| D8 | 测量器早期版本漏计 bbox 边缘的周长，导致 `compact` 虚高约 4 倍（切面曾算出 1.10，超出 4πA/P² 的理论上限 1）。已于 2026-11-12 修正，本文件所有阈值基于修正后版本 | 若有人用旧版重跑，数字对不上 |

## §E 冻结含义

1. 本文件冻结后，生产端只按 §A/§B 迭代，不再改动要求；
2. 若评审方在 N1 阶段否决某条款，执行方修改后重新冻结，版本号 +1；
3. N2 验收时**只**用本文件的条款判，不临时新增标准。
